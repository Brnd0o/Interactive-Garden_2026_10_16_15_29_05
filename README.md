This WEBGL sketch is a 3d daisy which can be scaled smaller or larger from the top left corner of the window while the daisy continuously spins in a loop, it also as a background of a garden which surrounds the entire daisy. Through this sketch, I was able to learn the basics of how to scale and manipulate different shapes in WEBGL and create an interactive object through multiple shapes. To create the 3D background, I used a code for panorama. The img = await loadImage('BiggerGardenImage.jpg'); loads the image of my choosing and creates the p5.image object, then to add the panorama I added the code panorama(img); which turns my image into a 3D background around the shape.

To create the shape of the flower I used the sphere(); to create the centre of the daisy, to create the petals of the daisy, not only did I use sphere(); for the petals but i used scale(2.0, 1.0, 0.3); to stretch them out to turn them into petal-like shapes. To make the 3D drawing rotate constantly, I used the code let angle = frameCount * 1.0; and rotateY(angle);. Finally i added Shininess(200); to the cylinders() that make up the pot for the daisy and added fill(); to each shape to give them all the appropriate colour. One challenge I faced when making my interactive garden was angling the petals to make the daisy which I found out I had to use rotateX(0);, rotateY(0);, rotateZ(0); to angle the petals to my liking.
